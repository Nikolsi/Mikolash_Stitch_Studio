ПЕРЕДАЧА ПРОЕКТА MICOLASH STITCH STUDIO

Сначала откройте 00_TZ_идея_и_материалы.txt — там кратко описаны идея сайта и задача по подготовке слоёв сцены.

Папки в архиве:
- concept-mockup — текущий самостоятельный HTML/CSS/JavaScript макет. Открыть index.html в браузере. Анимация персонажа сейчас отключена.
- animation — исходные изображения и подготовительные наборы сцены, персонажа, кресла, ковра и вышивальной машины.
- Сцена-портфолио (EN DE)-html — предыдущая версия сайта, справочник по содержанию и оформлению.
- micolash-animated-banner-starter — прежний прототип анимированного баннера.
- 05_previous_chair_materials — полученные ранее материалы кресла и композит для ориентира; фон без кресла в этой папке черновой и содержит следы реконструкции.

Все локальные ресурсы текущего макета находятся внутри concept-mockup; для его просмотра сервер не нужен. Папки старого сайта и starter включены как справочные материалы, а не как текущая версия.
