# Micolash Stitch Studio

Сайт-визитка специалиста по оцифровке дизайнов для машинной вышивки и «живая» сцена мастерской в духе Lo-fi.

| Папка | Что внутри |
|---|---|
| `concept-mockup/` | главная страница сайта (HTML/CSS/JS, без сборки); содержит интерактивные окна и встроенную анимированную сцену |
| `animation/studio_animation_layers_v3/` | слои сцены, кадры персонажа, сменяемый контент, превью анимации, PSD/ORA — см. `README_RU.txt` |
| `animation/studio_animation_layers_v3/content/` | постеры и экраны мониторов, инструкция по замене: `README_CONTENT_RU.md` |
| `00_TZ_идея_и_материалы.txt` | техническое задание |
| остальное | исходные материалы и прежние версии (справочно) |

Чтобы открыть сайт локально, открой `index.html` в корне проекта: он перенаправит на готовую главную страницу. Все пути к анимации относительные, отдельный сервер и сборка не нужны.

Сайт собирается и публикуется GitHub Actions (`.github/workflows/pages.yml`) при каждом пуше в `main`.
На Pages попадают только нужные вебу файлы (без PSD/ORA и исходников).
