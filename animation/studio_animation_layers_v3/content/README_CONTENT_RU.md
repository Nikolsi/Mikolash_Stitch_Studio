# Сменяемый контент сцены (для людей и агентов)

Цель: менять постеры, картинки на мониторах и неоновую вывеску, **не трогая анимацию и слои**.

* Файлы лежат в `content/<id>.png`. По умолчанию это вырезки из исходной сцены, поэтому сцена выглядит как оригинал.
* Чтобы заменить картинку, **положите новый файл с тем же именем** (PNG/JPG/WebP). Размер может быть любым, важна пропорция: картинка вписывается с обрезкой (`object-fit: cover`).
* Мониторы могут показывать видео: укажите в `content_slots.<id>.file` путь к `.mp4`/`.webm`. Видео играет без звука и по кругу.
* Если нужно подогнать тон под тёплый свет мастерской, впишите CSS-фильтр в `content_slots.<id>.filter`, например `"sepia(.15) saturate(.9) brightness(.92)"`.
* Слоты описаны в `04_guides/layer_map.json` → `content_slots`, а превью читает **`06_web_preview/scene_data.js`**. Меняете путь или фильтр — правьте оба файла одинаково.

## Неоновая вывеска («баннер»)

* Слой `01_scene_layers/00b_neon_sign.png`: полный холст 1672×941, RGBA, трубки и свечение. Стена под ним уже чистая.
* Замена: новый RGBA-PNG **того же размера холста**, вывеска примерно в зоне x 380–655, y 118–318. Мягкое розовое свечение на стене тоже должно быть внутри PNG (полупрозрачными пикселями).
* Мерцание задаётся в CSS (`.neon`), для новой вывески его менять не нужно.

## Чего НЕ делать, чтобы не сломать анимацию

1. Не менять размер холста (1672×941) и не сдвигать слои из `01_scene_layers`.
2. Не редактировать `00_background_clean_plate.png` в зонах кресла, машинки, неона и лежанки: под ними восстановленный фон, по которому ходят подвижные части.
3. Не менять порядок слоёв: персонаж всегда **над** машиной и **под** креслом, собака под бортиком лежанки.
4. Не вписывать текст и картинки прямо в фон. Для постеров и экранов есть слоты, для вывески есть `00b_neon_sign.png`.
5. Монитор частично закрыт спинкой кресла, а при стоянии за креслом — головой персонажа. Важное содержимое экрана держите в верхних 2/3.

## Если меняется вся иллюстрация мастерской
Тогда нужно заново вырезать слои (кресло, машина, неон, лежанка) и восстановить фон. Это делают скрипты из `07_tools_source/`
(SAM + LaMa, см. README_RU.txt). Простой заменой файла здесь не обойтись.
