ПАКЕТ PNG-КАДРОВ ПЕРСОНАЖА

Все изображения — отдельные PNG с альфа-прозрачностью. Из кадров удалён checkerboard-фон; в самих позах нет столов, стульев, мониторов или вышивального станка.

Содержимое:
- idle: 3 стоячие позы, включая основной образ.
- computer_and_stand: 2 сидячие позы и 2 переходных кадра вставания.
- walk_side: 6 кадров ходьбы в профиль.
- walk_away: 3 кадра разворота/ходьбы спиной.
- lean_inspect: 3 кадра наклона для осмотра.

Итого: 19 отдельных PNG-кадров. Исходные пропорции сохранены. Для веб-анимации задавайте одинаковую высоту изображения и выравнивание по нижнему краю.

Примечание: чистый лист получен перерисовкой выбранного референса с удалением мебели и оборудования; отдельные PNG вырезаны из листа автоматически по прозрачным силуэтам.
