# Micolash Stitch Studio — концепт-макет

## Открыть макет

Дважды щёлкни `index.html` или открой его в браузере. HTML, CSS, JavaScript, шрифты системы и все изображения для макета находятся в этой папке. Для просмотра не нужен локальный сервер.

Интернет понадобится только при переходе по внешним ссылкам на соцсети.

## Структура

- `index.html` — разметка и нижняя панель навигации.
- `styles.css` и `styles-overrides.css` — оформление и адаптация экранов.
- `script.js` — переключение языка и окон, сравнение примеров.
- `assets/background/` — фон мастерской.
- `assets/character/` — прежние тестовые кадры, сохранены для сравнения.
- `assets/studio-animation/` — выровненные кадры персонажа, исходная сцена, слои кресла и передний слой ковра.
- `assets/examples/` — локальные изображения для сравнения «исходник / вышивка».
- `assets/icons/` — иконки навигации из старого макета.
- `assets/process-embroidered.png` — иконка Ablauf.

## Персонаж

Анимация персонажа отключена в текущем макете. Кадры, фоновые слои кресла и ковёр сохранены в `assets/studio-animation/`, чтобы можно было вернуться к ним позже.

Для макета используется исходный фон без дополнительных слоёв поверх него.
